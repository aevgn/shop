
# Online Store Backend

A REST API for an online store built with Java and Spring Boot. The application supports product and category management, JWT authentication, shopping cart operations, and order processing.

## Features

- User registration and JWT authentication.
- Product and category CRUD operations.
- Shopping cart management.
- Order creation and total price calculation.
- PostgreSQL database integration.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA / Hibernate
- PostgreSQL
- JWT
- Maven
- JUnit
- Postman

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/aevgn/shop.git
   cd shop
   ```

2. Create a PostgreSQL database named `shop`.

3. Configure your database credentials in `application.properties`.

4. Run the application using your IDE or Maven.
